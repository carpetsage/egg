# `lib/` — shared library

This is shared code. 21 of the 24 workspaces in `pnpm-workspace.yaml` declare a dependency on it — `ui`, `eicoop`, and most `wasmegg/*` apps.

## Backwards compatibility

Treat any change to an exported signature, return shape, or thrown-error contract as potentially breaking, and say which consumers are affected. Be strict about this here in a way that would be inappropriate inside a single app — a local refactor in one app is cheap, the same refactor here is a cross-workspace migration.

**Name the actual consumers, not the whole repo.** Depending on the `lib` package is not the same as importing a given symbol from it, so trace the specific export being changed to the files that actually use it. A finding that says "this may affect all workspaces" without having checked is noise; one that names two concrete call sites is actionable.

Widening a return type, making a previously-required field optional, or changing when a function throws rather than returns are all breaking in practice even when they type-check.

## `lib/api/`

This wraps the private Egg, Inc. API, which is undocumented and not under our control.

- Flag missing error handling on network calls and unvalidated assumptions about response shape. A response field that exists today may be absent tomorrow.
- Flag any change that could send malformed requests upstream.
- Do **not** suggest adding retries, backoff, or polling that would increase load on the upstream API without a specific reason — this is a community tool hitting someone else's private endpoint, and being a considerate client matters more than resilience here.

## `lib/proto/` and `lib/sandbox/`

`proto/index.js`, `proto/index.d.ts`, `sandbox/schema.js`, and `sandbox/schema.d.ts` are generated by `make` from the `.proto` sources and are not committed. If they appear in a diff, something has gone wrong with `.gitignore` — say so rather than reviewing their contents.
